# Спина: карта, грыжи и упражнения

Интерактивная образовательная страница: анатомия позвоночника (кости, диски, связки, мышцы, нервы),
как выглядит грыжа диска, 17 упражнений с анимацией и конструктор личного комплекса.

- Открыть: https://subudaj.github.io/spine-guide/
- Исходники: `src/`, сборка в один файл: `python3 tools/build.py` → `dist/index.html` и `docs/index.html`.

Не является медицинской консультацией.
